Causal analysis of ecology, subsistence composition, and social organization in trans-historical small-scale farming societies using mixed-type Bayesian networks

Authors: Rosy Oh and Man-Suk Oh

R code for learning a Bayesian network (BN) from mixed continuous/categorical cross-cultural data on 157 small-scale farming societies, and for quantifying interventional (causal) effects among three domains of variables: ecology, subsistence composition, and social organization.

Overview of the pipeline

The main analysis is run from main.rmd.

Step Section in main.rmd Description
1 Read data and pre-process Read the data, merge Camp into Hamlet, convert categorical variables to factors
2 Normalize and standardize Yeo-Johnson transformation (bestNormalize), then scaling to mean 0, SD 1
3 Blacklist Forbidden arcs from domain knowledge (see below)
4 Structure learning and arc selection tpc() with the mixed-data CI test mixCItest on B bootstrap samples (each of size 80% of the data); arc strength and direction across bootstrap networks; arcs with strength ≥ threshold and direction ≥ 0.5 are kept
5 Consensus DAG DAG built from the selected arcs (arcs that would create a cycle are skipped), and its plot
6 Model fitting Continuous nodes: linear regression on parents (lm); discrete nodes: multinomial logistic regression (nnet::multinom)
7 Interventional analysis Monte Carlo simulation of the do-operator; interventional probabilities, ratios and 95% CIs
8 BIC Custom BIC for the hybrid DAG (no Conditional-Gaussian restriction)

Sections 6–8 use the network stored in avg_graph: the consensus DAG from Section 5, or an alternative network from the sensitivity analysis (see below).

Variables

Domain Variables
Ecology (5) DistanceCoast, Elevation, Slope, AnnualTemp, MonthlyPrecip
Subsistence (4) Hunt_Agri, Animal_Agri, Fish_Agri, Gather_Agri: additive log-ratio (ALR) of each subsistence share relative to agriculture
Social organization (4) CommSize (continuous); SettlementType, CommOrg, HouseholdOrg (categorical)

Blacklist (domain constraints)

  • Ecology is exogenous: no arcs from subsistence or social organization into ecology.
  • Within ecology: Geography (DistanceCoast, Elevation) → Topography (Slope) → Climate (AnnualTemp, MonthlyPrecip); reverse arcs are forbidden. There is no arc between the two geographic variables, since neither causes the other.
  • No arcs among subsistence variables. The ALR variables share the same reference category (agriculture), so dependence among them partly reflects the compositional constraint rather than causal relationships.
  • Optional ordering between subsistence and social organization, set by direction (see Options).

Interventional analysis

For each outcome X (subsistence and social-organization variables in the DAG) and each ancestor Y of X:

  • Continuous Y: compare do(Y ≤ median) with do(Y > median). Values of Y are drawn from the observed data in the corresponding region, and all descendants of Y are re-simulated from the fitted local models (10⁶ Monte Carlo samples).
    • Continuous X: P(X > median of X | do(Y))
    • Categorical X: P(X = k | do(Y)) for each level k
    • Ratio: P(· | do(Y > median)) / P(· | do(Y ≤ median)), with a 95% CI from the delta method on the log scale
  • Categorical Y: P(X | do(Y = k)) for each level k of Y.
  • 95% CIs for probabilities use the Wilson score interval.

Supplementary analysis: discrete BN (main_disc.rmd)

main_disc.rmd repeats the pipeline after discretizing all 10 continuous variables (5 ecology, 4 ALR subsistence, CommSize), for comparison with the mixed-data analysis:

  • Discretization (option disc_method): "median" (Low / High; ties at the median go to Low) or "tertile" (Low / Medium / High).
  • Structure learning: tpc() with the G-square test disCItest; same blacklist, bootstrap scheme, alpha and arc-selection rule as main.rmd.
  • Local models: empirical marginal distribution for root nodes, multinomial logistic regression for all other nodes.
  • Interventional analysis: P(X = k | do(Y = j)) with 95% CIs for every level of every ancestor Y (no ratios, since there are no continuous interventions).
  • Output file names contain disc_<disc_method>_<direction>_thr<k>, so they do not overwrite the results of main.rmd. Bar charts are not produced.
  • Its BIC is not comparable with that of main.rmd, because the data differ.

Data

data/dat_score_ALR_agri_157.csv has one row per society (157 societies) and 14 columns, in this order:

  1. Society ID (dropped in the script)
  2. 5 ecology variables
  3. 4 subsistence variables (ALR-transformed)
  4. 4 social-organization variables

The script selects variables by column position, so the column order must be kept.

The data are based on Palacios et al. (2022), with ecological variables taken from D-PLACE.

Requirements

  • R (≥ 4.2 recommended)
  • Bioconductor: graph, RBGL, Rgraphviz
  • CRAN: pcalg, bnlearn, micd, tpc, nnet, igraph, dplyr, tidyverse, GGally, readxl, httr, bestNormalize, ggplot2, gridExtra

The first chunk of main.rmd installs any missing Bioconductor and CRAN packages. bestNormalize is installed by fn_normalize.R if needed; gridExtra may need to be installed separately:

install.packages("gridExtra")

How to run

  1. Clone the repository and open it as the working directory (e.g. an RStudio project).
  2. Put the data file in data/ and create an empty output/ folder.
  3. Set the options at the top of Section 1 in main.rmd.
  4. Run the R chunks in order (or knit the file).

Options

Option Value used Meaning
direction "none" Ordering between subsistence and social organization: "none" (no constraint), "sub_to_soc" (subsistence → social organization only), "soc_to_sub" (social organization → subsistence only), or other user-defined constraints, which must be specified in Section 3 (Blacklist).
threshold 0.3 Minimum arc strength for the consensus DAG
B 10000 Number of bootstrap replicates (a smaller value, e.g. 100, runs faster for testing)

Other fixed settings: CI-test significance level alpha = 0.1; direction cutoff 0.5 for arc selection (arcs with direction < 0.6 are drawn dashed); 10⁶ Monte Carlo samples per intervention; random seeds 2374 (bootstrap) and 0428 (simulation).

To compare the scenarios, run main.rmd once for each value of direction and compare the BIC files (lower is better).

Sensitivity to arc orientation (fn_sensitivity_analysis.R)

Arcs of the consensus DAG whose direction probability is below 0.6 are treated as having uncertain directions. Alternative networks are built by reversing these arcs in every combination, keeping all other arcs unchanged. Each network is then fitted, its interventional effects re-estimated, and the networks compared by BIC.

With the settings used in the paper (direction = "none", threshold = 0.3), two arcs are uncertain (Gather_Agri → CommSize, direction 0.51; CommSize → Hunt_Agri, direction 0.56), giving four networks:

Model Network
M0 Consensus DAG (directions learned from the data)
M1 Gather_Agri → CommSize reversed
M2 CommSize → Hunt_Agri reversed
M3 Both arcs reversed

fn_sensitivity_analysis.R is a script (it defines no function) that uses objects created by main.rmd. For each model:

  1. Run Sections 1–5 of main.rmd (once; the bootstrap does not need to be repeated for each model).
  2. Set sens_model in fn_sensitivity_analysis.R to "M0", "M1", "M2" or "M3", and run the script, e.g. source("fn_sensitivity_analysis.R"). It
    • takes the consensus DAG saved in Section 5 (e.g. avg_graph_none),
    • lists the arcs with direction probability < 0.6 (uncertain_arcs),
    • reverses the arcs for the chosen model, checks that the result is a DAG, and stores it in avg_graph,
    • sets out_label (e.g. none_M1) for the output file names.
  3. Run Sections 6–8 of main.rmd.

Repeat steps 2–3 for M0–M3 and compare the files BIC_<label>_thr3.csv (lower is better).

The two arcs to reverse are written in the script. If threshold or the data change, check uncertain_arcs and edit the arc names in Step 3-1 of the script.

Output (in output/)

File Content
arc_strength_<direction>_thr<k>.csv Strength and direction of every arc observed in the bootstrap networks
selected_arcs_<direction>_thr<k>.csv Arcs in the consensus DAG
BN_<direction>_thr<k>.tif / .png / .pdf Plot of the consensus DAG
intervention_conti_Y_thr<k>_<label>.csv Results for continuous interventions (probabilities, difference, ratio, 95% CIs)
intervention_cat_Y_thr<k>_<label>.csv Results for categorical interventions, P(X | do(Y = k)) with 95% CIs
barplot_<X>_<label>.pdf / .png Interventional probability ratios for outcome X
barplot_<X>_HouseholdOrg.pdf / .png P(X | do(HouseholdOrg = k))
BIC_<label>_thr<k>.csv Log-likelihood, number of parameters and BIC of the network used in Sections 6–7 (compare across M0–M3 for the sensitivity analysis)

<k> = 10 × threshold (e.g. thr3 for 0.3). <label> = out_label: <direction> for the consensus DAG (M0) and <direction>_<model> for the alternative networks (e.g. none_M1).

The barplot_<X>_HouseholdOrg files do not include the model label, so each run overwrites them. In the paper these effects are identical across M0–M3.

Notes

  • With B = 10000, structure learning takes a long time. Save intermediate objects with the saveRDS() lines in main.rmd (commented out) so later sections can be rerun without repeating the bootstrap.
  • The custom BIC follows the convention lower is better, the opposite of bnlearn::score().
